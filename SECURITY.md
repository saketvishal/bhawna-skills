# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use GitHub's private vulnerability reporting feature when enabled for the repository.

## Data handling

When semantic evaluation is enabled, Bhawna Skills sends the objective, constitution, and invariant catalog to the configured model endpoint. Users are responsible for choosing a provider and deployment mode appropriate for their data classification.

API keys are read from environment variables and should never be committed to the repository.
