# Security

See [SECURITY.md](https://github.com/saketvishal/bhawna-skills/blob/main/SECURITY.md) in the repository.

Objectives, constitutions, and invariants may contain proprietary information. Semantic evaluation sends that content to the model endpoint you configure. Review the provider’s data-handling terms first.

Discovery skips secrets and generated trees and honors `.bhawnaignore`.

Report vulnerabilities privately as described in SECURITY.md. Do not file public issues with exploit details.
