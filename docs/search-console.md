# Search Console (human steps)

The coding agent cannot verify Google or Bing ownership or force indexing.

## Google Search Console

1. Open [Google Search Console](https://search.google.com/search-console).
2. Add a URL-prefix property: `https://saketvishal.github.io/bhawna-skills/`.
3. Verify ownership with a method Google supports (HTML file, DNS, or meta tag). Do not commit a verification file unless you supply the exact token for this property.
4. Submit sitemap: `https://saketvishal.github.io/bhawna-skills/sitemap.xml`.
5. Request indexing for:
   - Home: `https://saketvishal.github.io/bhawna-skills/`
   - Getting started: `https://saketvishal.github.io/bhawna-skills/getting-started/`
   - InvariantGate: `https://saketvishal.github.io/bhawna-skills/invariant-gate/`

Indexing can take days or weeks. A reachable site is not the same as “indexed.”

## Bing Webmaster Tools (optional)

1. Open [Bing Webmaster Tools](https://www.bing.com/webmasters).
2. Add the same GitHub Pages URL.
3. Verify ownership.
4. Submit the same `sitemap.xml`.

Do not add extra SEO SaaS or trackers for this.
