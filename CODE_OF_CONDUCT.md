# Code of Conduct

We are committed to a respectful, constructive, and inclusive project community.

## Expected

- Be considerate.
- Critique ideas rather than people.
- Assume good intent while requiring evidence.
- Do not harass or discriminate.

## Enforcement

Maintainers may remove contributions or participation that violate these expectations. Report conduct issues through GitHub (private contact to maintainers, or a security advisory if the issue is also a vulnerability).
